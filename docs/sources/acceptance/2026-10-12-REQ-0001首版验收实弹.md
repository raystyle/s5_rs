## 发现与回报项

1. garage 匿名读写未开 [已否证]:无凭据 ls/put 均 403 AccessDenied。
   属服务面 garage 配置项(桶授权面),非 s5 债;按总台令如实回报。
2. del 对从未存在键不幂等 [已验证,与手册宣称相抵已否证]:garage
   v1.1.0 对从未存在的键 DeleteObjects 返 NoSuchKey,s5 忠实透传退 1;
   手册与 clap 注释称键不存在同样报成功。改法待总台裁定:错误映射
   吞掉(对齐手册)或改手册措辞(对齐 garage 实况)。
3. config set 固化环境值 [已验证]:`config set` 走 load(env 合并)再
   整档 save,当次 S5_* 环境值会被写入 0600 密档(init 落纯缺省不受
   累;控变探针坐实)。0600 权限缓解;建议 set 只落文件态,待裁定。
4. s5 无 stat 动词 [已观察]:总台令基本面列有 stat;现契约以 ls 与
   get 承载同等信息,如实记契约面差异。
