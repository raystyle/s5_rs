# ADR-0001:零感知凭据配置层

关联 REQ-0001。

## Context

用户裁定:内网 s2 s3 不需要密钥,访客共享可读可写即可。但后端实况:
garage 实测不支持匿名访问(403,上游 roadmap 未排期),s2-lite 无令牌 API
(issue #28 未排期,官方口径「用你自己的边界挡住」)。命令面带凭据参数
会让密钥进 shell 历史、进 agent 轨迹、进 ps 输出。

## Decision

凭据全部收进 s5 配置层,agent 命令面零凭据参数:

1. 配置文件 TOML(`s5 config init/set/show/path` 管;`S5_CONFIG` 覆盖
   路径),权限 0600,原子写(临时文件加改名),永不进 git。
2. 环境变量逐键覆盖(S5_S3_*、S5_S2_*),读序:环境变量 > 配置文件 >
   随包缺省(dev 指向);无头与测试场景用。
3. 展示面(`config show`)密钥类字段掩码(前 4 字符加省略号),任何
   命令输出不回显明文。
4. s2 token 用占位 `ignored`(lite 无鉴权面);内网边界即信任边界。

## Consequences

- 好:密钥零进 shell 历史、零进 agent 对话轨迹;agent 面保持
  「直用即通」;换生产桶只改配置不改命令。
- 好配置文件即唯一敏感面,0600 加 gitignore 双保险。
- 坏:凭据轮换要动配置文件(环境变量可临时覆盖);生产 key 分发不经
  本仓(总台管,首版后接)。
- 若上游 garage 落地匿名面或 s2-lite 落地令牌 API,本裁定可局部松绑,
  但命令面零凭据参数的形态不动。
