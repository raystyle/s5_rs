# REQ-0002:全开放共享模型与建桶动词 bucket create

## Scenario

全开放共享模型落定(总台令 s5-02,2026-10-12):s5 是全 agent 自由使用
的共享文件/流/频道/桶服务。建流已自由(append 自动建);建桶需动词与
admin 道;模型需文档化进手册面,匿名语义边界讲清(garage SigV4 由
config 层吃掉,agent 永不接触钥)。

## Criteria

- [x] 建桶动词 `s5 bucket create <名>`:garage admin 道(部署面 v1
  Admin API,POST /v1/bucket 加 /v1/bucket/allow),建桶即授权配置层
  当前 s3 key 读写(非 owner);后端错误码原码透传(重名 409
  BucketAlreadyExists)
- [x] admin 凭据入 0600 档零感知:s3.admin_endpoint/s3.admin_token 进
  白名单与环境覆盖(S5_S3_ADMIN_*),show 掩码;老配置档缺键兼容
  (serde default)
- [x] 建流保持自由:append 自动建流,不引入预建步骤
- [x] 模型文档化进 --llms 面:共享模型节(全开放、共享钥零感知、匿名
  语义边界)加 bucket create 常用例;子命令表由活命令树自动带上
- [x] 测试:未配 admin 拒(Config 信封)恒跑;admin 真回环(建桶、
  授权即用、清尾)门控 S5_TEST_GARAGE_ADMIN 加 S5_S3_ADMIN_TOKEN,
  缺件跳过
